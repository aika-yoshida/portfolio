株式会社Digsy
LP / メディアサイト

会社設立に伴うホームページ新設に合わせて制作した、サービスLPとコンテンツページのデザイン。2ページを通してブランドの一貫性を意識しました。

Role / 担当範囲
デザイン制作
Year / 制作年
2023
Type / 形態
実務
Tool
Figma
01Overview

初めてのLP制作を、決められた枠の中で形にする

会社設立に伴うホームページ新設で、サービスLPとメディアサイトの2ページを担当。自分にとって初めてのLP制作で、納期とワイヤーフレームはディレクターが指定する中、色・イラスト・あしらいの参考サイトを自分で探しながら、それぞれ1週間でビジュアルに落とし込んだ。

担当：デザイン制作（LP・コンテンツページ）

02Constraints

制約

デザイン制作期間はLP・メディアサイトそれぞれ1週間。自分にとって初めてのLP制作だった。納期とワイヤーフレームはディレクターが指定しており、情報設計そのものは裁量の外にあった。

03Insight

課題とインサイト

ターゲットはバックオフィスのアウトソーシング活用を検討している方。ディレクターが指定した「悩みの提示→解決できること→選ばれる理由→導入事例→Q&A」という構成の中で、ロゴカラーのコーラル・オレンジを基調に、親しみやすさと業務としての信頼をどう両立させるかが課題だった。

04Process

プロセス

A

参考サイトのリサーチ

色・イラスト・あしらいそれぞれについて参考サイトを自分で探し、方向性を固めた。

B

LP：イラストと写真の使い分け

親しみやすさと信頼を両立するため、イラストと写真を組み合わせた。

C

メディアサイト：優しい個性の演出

ロゴカラーのコーラルにふんわりとした背景を合わせ、記事をカード状に並べて情報を探しやすくした。

D

2ページ間のトーン統一

LPとメディアサイトでトーンを揃え、サイト全体でブランドの一貫性を保った。

05Results

結果

公開後の反応や問い合わせ数の変化は確認できていない。

06Reflection

振り返り

初めてのLP制作を、納期・ワイヤーフレームが決まった状態から任された経験だった。限られた裁量の中でも、色やイラストの参考サイトを自分で探しながらビジュアルの方向性を固めたプロセスは、その後のデザイン判断に活きている。
